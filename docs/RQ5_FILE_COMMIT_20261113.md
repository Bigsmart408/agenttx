## 暂停后的运行时优化（2026-11-14）

正式实验保持暂停，已完成的 682 个正式测量及暂停时未完成的样本分别保留；
以下使用同一 Ext4 VM 的独立优化负载，不混入正式矩阵。

上轮改为基础检查点加不可变增量、按需构建完整历史，并缓存目录拓扑。
本轮进一步将大批普通文件直接批量复制到不可变增量目录，减少逐文件发布
内容及额外硬链接；未改变的状态仍沿父历史版本复用。白化节点、硬链接和
特殊文件使用原捕获路径，可与普通文件在同一批中处理。捕获前共享祖先
版本检查，并去除重复的文件 stat；复制失败或源版本变化会清理部分结果
并退回原捕获流程。完整内容哈希继续执行，以捕捉持久 mmap 写入。

早期/中间/最终历史状态和提交后的完整路径、内容、模式。
